# Third-party notices

The widgets in `arm1-widgets/`, `arm2-widgets/` and `excluded-widgets/` are code transplanted from the open-source
Flutter repositories below. In arm 2, `spm isolate` also inlined declarations from the pub.dev packages listed further
down. That code is **not** covered by this repository's CC BY 4.0 licence. It stays under its own licence, which is
given here with its copyright notice. The screen only let through code under MIT, Apache-2.0 or BSD-3-Clause
(rules R17 and R18).

**The files were changed.** None of the widget files is a copy of the original file. They were cut out of the source
repositories, rewritten to be self-contained (imports stripped, dependencies replaced by stand-in declarations), and in
arm 1 changed again by the generated variants. For the Apache-2.0 repositories this is the notice of changes that section
4(b) of that licence asks for. Where a file is a generated variant or a revision of a widget, it is a derivative of the
original and is not the original author's work as published.

Licences were read from each repository's and package's own licence file. Where a repository's file names no copyright
holder, the entry says so. The full licence texts are at the end of this file. None of the nine Apache-2.0 repositories has a
`NOTICE` file in its root (checked 2026-10-08).
